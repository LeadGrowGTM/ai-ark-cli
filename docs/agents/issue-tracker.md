# Issue Tracker

## Where Issues Live

Issues for ai-ark-cli are tracked on GitHub:

**Repository:** https://github.com/LeadGrowGTM/ai-ark-cli  
**Issues tab:** https://github.com/LeadGrowGTM/ai-ark-cli/issues

## Workflow

1. File bug reports or feature requests at the Issues tab above.
2. Apply the appropriate triage label from `triage-labels.md` when triaging.
3. Link issue numbers in commit messages and PR descriptions (`fixes #<n>`).

## Notes for Agents

- This is a single-repo, single-context project. All issue tracking happens in the GitHub Issues tab above.
- There is no separate project management board or Jira workspace — GitHub Issues is the canonical source of truth.
- When a search/export issue is filed, always ask for the exact CLI command (flags) and the API error message from stderr. These are the two pieces of information that cut debug time by 80%.
